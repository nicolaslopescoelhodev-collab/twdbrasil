VERSÃO PRONTA PARA VERCEL

1. Abra a pasta TWD-Brasil-Online-Vercel.
2. Envie o conteúdo dessa pasta para a raiz do repositório twdbrasil no GitHub, substituindo os arquivos de mesmo nome, e confirme o commit na branch main. O package.json deve ficar na raiz.
3. Na tela New Project da Vercel, mude Application Preset para Next.js.
4. Mantenha Root Directory como ./ e os padrões de Build and Output Settings.
5. Não é necessário preencher Environment Variables para esta versão.
6. Clique em Deploy.

Os comandos de instalação e build estão no vercel.json.
O visual, as imagens, os mapas e as regras foram preservados.
O login real do Discord continua pendente.

Verificações: build de produção Next.js, TypeScript, página e assets servidos com HTTP 200 em servidor local. A publicação na sua conta Vercel ainda será feita por você.
